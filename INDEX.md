## ⚡ Aide Rapide

### ❓ Questions Fréquentes

**Q : Mes sauvegardes vont-elles fonctionner ?**  
A : Oui, 100% compatibles. Voir [MIGRATION.md](MIGRATION.md)

**Q : Qu'est-ce qui a changé ?**  
A : Système de reliques évolutif + shop. Voir [COMPARAISON.md](COMPARAISON.md)

**Q : Où sont les fichiers `*1.js/css/html` ?**  
A : Fusionnés et supprimés. Voir [REFACTORISATION.md](REFACTORISATION.md#fichiers-supprimés)

**Q : Comment upgrader mes reliques ?**  
A : Bouton 💎 → cliquez sur "Upgrade". Voir [LISEZ-MOI.md](LISEZ-MOI.md#système-abyssal-relics)

**Q : C'est quoi les AP ?**  
A : Abyssal Points, obtenus lors des Ascensions. Voir [LISEZ-MOI.md](LISEZ-MOI.md)

**Q : Le layout a changé ?**  
A : Non, layout original conservé. Voir [REFACTORISATION.md](REFACTORISATION.md#layout-conservé)
